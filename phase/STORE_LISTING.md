## 포지셔닝

**"감상 후 개인 기록 + AI"** — 별점 매기는 앱이 아니라, 본 걸 기억하는 앱.
v1까지는 "기록하는 방식"(AI 검색·스크린샷)이 차별점이었다면, Phase 13 완료로
"기록의 형태" 자체(수식어·다면 별점)가 더해짐 — 인생영화도, 별점도 하나로
끝나지 않는다는 것.

전면 배치하는 4가지 차별점:
1. **AI 자연어 검색** — "홍콩 느와르" 같은 말로 작품을 찾아 기록
2. **스크린샷 기록** — 캡처만 올리면 AI가 자동 인식, 타 앱 기록 이관 포함
3. **수식어** — "같이 보고 싶은", "3회차에 전율"처럼 나만의 부문으로 인생영화를
   모으고, 이미지 카드로 저장·공유
4. **다면 별점** — "작품성은 5점, 나에겐 3점"처럼 내가 만든 기준으로 같은
   작품에 여러 별점을 매김

기존 3번째 차별점이던 **N회차 관람 + 감상 맥락**(재시청 이력, 누구와/어디서/
어떤 기분으로 봤는지)은 독립 항목에서 내려 3·4번 설명 안에 맥락으로만 남김 —
"다시 볼 때마다 달라지는 감상"이라는 스토리가 수식어·다면 별점과 자연스럽게
이어져서 굳이 5번째 항목으로 쪼갤 필요가 없다고 판단(차별점 항목 수는 4개로
유지). 기능 자체가 빠진 건 아니고, "자세한 설명"의 기본 기록 목록에는 그대로
남아 있음.

**의도적으로 배제한 표현**: "OTT 통합검색", "어디서 볼 수 있는지", 최저가·랭킹·인기
류 — 경쟁사(왓챠피디아 등 OTT 통합 랭킹 서비스) 영역으로 읽힐 수 있는 문구는
전면 배제. 경쟁사명은 임포트 기능 설명(캡처 대상 안내) 맥락에서만 사용하고
홍보 문구·타겟 페르소나 설명에는 쓰지 않음.

**Phase 12에서 제거된 기능 관련 문구 정리**: "취향 프로필 기반 오늘의 추천"
(DiscoverPage), "이 작품을 좋아하셨다면"(DetailModal 추천 섹션)은 Phase 12.1에서
코드 자체가 삭제됐으므로 이전 버전에 있던 관련 문구를 전부 제거함. discover/chat
AI 채팅 추천은 코드는 남아있으나(내 기록 기반 발견 — 별도 차별점), 이번 리스팅은
"기록" 포지셔닝에 집중하기 위해 전면에 내세우지 않고 이번 초안에서는 생략함
— 포함을 원하면 알려주세요.

## 5. 스크린샷 캡션 초안 (6개 화면, 순서 지정)

Phase 12.4에서 다크모드·터치 타깃을 점검한 촬영 대상 6개 화면을 기반으로,
Phase 13 완료에 맞춰 재검토. **수식어 페이지·공유 카드 미리보기가 새로
들어감** — 신규 차별점(수식어·다면 별점)이 스크린샷에 하나도 없던 공백을
메움. 44px 터치 타깃은 13.1/13.2/13.3 각 커밋에서 이미 적용된 화면이라
Phase 12.4 기준을 그대로 충족.

자리를 만들기 위해 기존 6개 중 **통계**(비고가 "보조"로 가장 낮았던 항목)와
**설정**("다른 앱 기록 가져오기" 진입점 — 차별점②의 보강 자료일 뿐 그 자체가
차별점은 아니었음)을 뺐습니다. 신규 항목(수식어·다면 별점)이 통계·설정보다
우선순위가 높은 실제 차별점이라는 판단인데, 6장 제한을 없애고 8장까지
채우면 통계·설정도 같이 살릴 수 있습니다 — 원하시면 알려주세요.

기존 3번째 캡션("몇 번째 관람인지, 누구와 어떤 기분으로 봤는지까지")은
포지셔닝 재편에 맞춰 상세 모달 캡션을 **다면 별점** 중심으로 교체(화면 자체는
동일 — 상세 모달 하나에 재시청 이력·시청 컨텍스트·다면 별점이 함께 보임).

차별점 4가지(AI 검색 → 스크린샷 → 수식어 → 다면 별점)가 먼저 보이도록 순서
재배치, 전체 개요(홈/다이어리)는 마지막.

| # | 화면 | 캡션 문구 | 비고 |

## 참고 — v1(Phase 12.5)과 달라진 점 요약 (v2, Phase 13 반영)

- 차별점을 3가지(AI 검색·스크린샷·N회차+맥락)에서 **4가지**(AI 검색·스크린샷·
  수식어·다면 별점)로 재편 — N회차+맥락은 독립 항목에서 내려 3·4번 설명 안에
  맥락으로만 남김(기능 자체는 "기본 기록" 목록에 그대로 유지)
- 핵심 훅 **"인생영화가 하나일 리 없잖아요"** 추가 — 자세한 설명 도입부에
  배치(짧은 설명은 글자 수 예산상 구체적 기능 키워드 우선, 판단 근거는 2번
  섹션 참고)
- 자세한 설명에 🏷️ 수식어 / ⭐ 다면 별점 섹션 신설, 기존 🔁 섹션(N회차+컨텍스트)은
  제거하고 그 내용을 "기본 기록 & 관리" 불릿 2개로 이관
- 짧은 설명 두 후보 모두 N회차 언급을 다면 별점 언급으로 교체
- 스크린샷 캡션: 나의 수식어 페이지·공유 카드 미리보기 2개 신규 추가, 상세
  모달 캡션을 다면 별점 중심으로 교체, 자리 확보를 위해 통계·설정 2개를 제외
  (8장까지 늘리면 함께 유지 가능 — 판단 필요 시 확인)
- "이런 분께 추천해요" 페르소나 목록에 수식어·다면 별점 대상 1줄 추가

### v1(Phase 12.5)에서 달라진 점 (참고용, 이번 갱신과 무관하게 유지된 이력)

- 리드 메시지를 "AI 추천"에서 "AI 자연어 검색 + 스크린샷 기록 + N회차/맥락 기록"
  3가지로 교체 (경쟁 분석 결과 포지셔닝 확정에 따름)
- 삭제된 기능("오늘의 추천", "이 작품을 좋아하셨다면") 관련 문구 전부 제거
- discover/chat AI 채팅 추천 언급을 이번 리스팅에서 생략(포함 여부는 별도 확인 필요)
- 타겟 페르소나 문구에서 경쟁사명(왓챠피디아) 제거 — 임포트 기능 설명에만 유지
- "평점 높은 거" 같은 랭킹 연상 예시 문구를 "홍콩 느와르" 예시로 교체
- 스크린샷 캡션 순서를 3가지 차별점이 먼저 보이도록 재배치
