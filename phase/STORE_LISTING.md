# Google Play 스토어 등록 텍스트 초안 (Stage 11.4.1)

> 스크린샷은 실기기/에뮬레이터 실행이 필요해 이 문서에서는 캡션 문구와
> 촬영 화면 리스트만 준비했다. 실제 촬영은 `phase/ROADMAP_V7.md`의
> "실기기 점검 대기 목록"에서 진행.

## 1. 앱 이름 (30자 이내)

Play Console 입력창에서 실제 글자 수를 다시 확인할 것 (한글 1자 = 1글자 기준).

**후보 1 (권장)**
> 미디어 다이어리 — 영화·드라마·애니 기록

**후보 2**
> 미디어 다이어리: 본 작품 기록장

**후보 3**
> 미디어 다이어리 - 감상 기록 & AI 추천

후보 1은 이미 `CLAUDE.md`/ROADMAP에 초안으로 있던 문구를 그대로 채택. 후보 2/3은
검색 키워드(기록장, AI 추천)를 다르게 배치한 대안.

## 4. 스크린샷 캡션 문구 (4~8개)

실제 스크린샷은 아래 "촬영 화면 리스트"에 맞춰 나중에 찍고, 캡션만 먼저 준비.

| # | 촬영 화면 | 캡션 문구 |
|---|---|---|
| 1 | 홈 (탭·카드 그리드) | 본 영화·애니·드라마, 한눈에 모아보기 |
| 2 | 큐레이션 체크 / AI 대화형 기억 복원 | 예전에 본 작품, AI가 대신 찾아드려요 |
| 3 | 스크린샷 인식 업로드 | 시청 화면 캡처만 올리면 자동으로 기록 |
| 4 | AI 채팅 추천 (DiscoverChatPage) | 대화하듯 물어보면 AI가 골라주는 다음 작품 |
| 5 | 통계 페이지 (도넛/바 차트) | 내 취향, 숫자로 확인하는 통계 |
| 6 | 연말 결산 슬라이드 | 한 해의 감상을 9장으로 요약하는 연말 결산 |
| 7 | 상세 모달 (시청 컨텍스트 포함) | 누구와, 어디서 봤는지까지 기록 |
| 8 | 공개 프로필 / 피드 | 친구와 취향 비교하고 함께 볼 작품 정하기 |

8개 중 최소 2~4개만 우선 사용해도 되며(Play Console 요구는 최소 2장),
1~5번을 우선순위로 추천.

## 5. 촬영 화면 리스트 (실기기/에뮬레이터 필요 — 실기기 점검 대기 목록으로 이관)

1. 홈 화면 (탭 전환 + 카드 그리드, 데이터가 어느 정도 채워진 상태)
2. 큐레이션 체크 or AI 대화형 기억 복원(MemoryChatPage) 중 더 화면이 매력적인 쪽
3. 스크린샷 인식 업로드 흐름 (신뢰도 배지 보이는 상태)
4. AI 채팅 추천 (DiscoverChatPage)
5. 통계 페이지 (StatsPage) — 차트가 실제 데이터로 채워진 상태
6. 연말 결산 (YearInReviewPage) — 슬라이드 1~2장
7. 상세 모달 — 시청 컨텍스트(누구와/어디서/기분) 섹션 보이게
8. 공개 프로필 or 피드(FeedPage)

촬영 전 데모 데이터가 어느 정도 쌓여 있어야 화면이 비어 보이지 않음 —
필요하면 스크린샷 촬영용 데모 데이터 세팅 스크립트를 별도로 만들어줄 수 있음
(ROADMAP 11.4.1에 이미 언급된 항목).
