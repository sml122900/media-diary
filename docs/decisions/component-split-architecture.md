# 기술 결정 — HomePage.jsx 컴포넌트 분리

## Problem (상황/문제)

> HomePage.jsx가 950줄에 달해 수정 시 충돌 위험이 크고, 새 기능 추가마다 단일 파일이 계속 비대해졌다.
> Phase 1~2 기능(포스터 교체, 통계, 필터, CSV)을 추가하면 1500줄을 넘을 것으로 예상됐다.

## Action (결정 및 근거)

> 컴포넌트, 훅, 유틸리티 세 레이어로 분리했다.

```
components/  — UI 렌더링 단위 (순수 표현)
hooks/       — 비즈니스 로직 + 상태 (데이터 가져오기, 캐시, CRUD)
utils/       — 순수 상수 / 헬퍼 (AWARDS, IMG_BASE 등)
```

분리 기준:
- 컴포넌트: props 받아 렌더링만 하는 단위
- 훅: 여러 컴포넌트에서 공유될 수 있는 상태 로직
- 유틸: 어디서든 임포트 가능한 무상태 상수/함수

## Result (결과)

> HomePage.jsx가 250줄로 감소.
> 각 컴포넌트가 독립적으로 수정 가능해졌고, 새 기능(PosterPicker, CsvImportModal 등)을 파일 하나 추가하는 방식으로 확장할 수 있다.

포기한 대안: 단일 파일 유지 + 섹션 주석 구분 → 파일이 계속 커지는 근본 문제 해결 불가.
