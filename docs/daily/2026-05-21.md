## 완료한 작업

### 1. 포스터 변경 시 제목 자동 업데이트

**요구사항**: PosterPicker에서 포스터를 선택하면 그 TMDB 결과의 제목이 자동으로 항목 제목에 반영

**변경 파일 및 내용**:

| 파일 | 변경 내용 |
|---|---|
| `PosterPicker.jsx` | `onApply(url)` → `onApply(url, title)` — TMDB 제목 함께 전달 |
| `DetailModal.jsx` | `handleApplyPoster(url, title)` — `setEditFields(prev => ({...prev, title}))` 추가 |
| `HomePage.jsx` | `handleUpdatePosterAndCache(id, url, title)` — title 파라미터 추가 |
| `useMediaList.js` | `handleUpdatePoster(id, url, newTitle)` — title 있으면 PUT 단일 호출 |

**설계 결정**:
- `newTitle`이 있을 때 `updatePosterItem(PATCH)`가 아닌 `updateMediaItem(PUT)`으로 전환
- 포스터+제목을 단일 API 호출로 처리해 stale state 문제 방지
  (PATCH 후 PUT 시 `item.poster_url`이 구 포스터를 사용해 덮어쓰는 문제 회피)
- `editFields.title`도 즉시 갱신해 편집 폼에서도 바로 반영

---

## 트러블슈팅

### stale state 문제 회피 (포스터+제목 순차 업데이트)

- **문제**: PATCH(포스터) → PUT(제목) 순서로 두 번 호출하면, PUT 시 `item.poster_url`이 아직 구 포스터라 포스터가 되돌아갈 수 있음
- **원인**: DetailModal의 `item` prop은 HomePage의 `detailItem` state에서 오는데, PATCH 이후 `setDetailItem`이 호출되지 않아 stale 상태 유지
- **해결**: `newTitle` 존재 시 처음부터 PUT 단일 호출로 포스터+제목을 함께 업데이트
