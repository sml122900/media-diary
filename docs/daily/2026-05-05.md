## 오늘 한 일

### 1. 미디어 다이어리 핵심 기능 전체 구현

기존 `media_diary.html` (바닐라 JS + localStorage)을 React + 백엔드 API로 완전히 마이그레이션했다.

**백엔드**
- `user_media` DB 테이블 설계 및 생성 (PostgreSQL, Supabase)
  - UNIQUE(user_id, title, year) 제약조건으로 중복 방지
- `/api/user-media` 라우터 신규 작성
  - `GET /` — 내 미디어 목록 조회
  - `POST /bulk` — 첫 로그인 시 기본 데이터 178건 일괄 삽입 (50건씩 배치)
  - `POST /` — 단건 추가 (upsert: 이미 있으면 업데이트)
  - `PUT /:id` — 정보 수정 (제목/연도/감독/출연 + 별점/리뷰)
  - `DELETE /:id` — 삭제
- `app.js`에 `initDB()` 내 테이블 자동 생성 로직 추가

**프론트엔드**
- `frontend/src/data/defaultMedia.js` 생성: 기본 미디어 178건 (영화 141 / 애니 24 / 드라마 13)
- `frontend/src/api/userMedia.js` 생성: axios 기반 API 래퍼 (JWT 헤더 자동 주입)
- `frontend/src/pages/HomePage.jsx` 전면 재작성 (1051줄)
  - 탭: 영화 / 애니 / 드라마 전환
  - 카드 그리드: TMDB 포스터 + 제목/연도/감독
  - 상세 모달: TMDB 정보·OTT 스트리밍·별점·리뷰 메모
  - 포스터 피커: TMDB 검색 결과에서 직접 선택
  - 추가 모달: 단건 (TMDB 검색) / 벌크 추가
  - 검색 & 정렬
  - 헤더: "안녕하세요 {이름}님" + 로그아웃 버튼

## 기술 결정

### CLAUDE.md 역할 이해
- **행동 지침 파일**: 클로드 코드가 새 세션 시작 시 자동으로 읽음
- **두 가지 역할 동시 수행**: 클로드 행동 규칙 + 프로젝트 맥락 기억
- 한영 혼용 완전히 OK — 지침은 영어, 기록은 한글 권장

### 문서화 구조 결정
```
프로젝트/
├── CLAUDE.md
└── docs/
    ├── daily/YYYY-MM-DD.md     ← 일지
    ├── decisions/[기술명].md   ← 기술 결정
    ├── troubleshooting/        ← 문제 해결
    └── par-materials.md        ← 이력서 소재
```

### 포트폴리오 도구 결정
| 도구 | 용도 |
|------|------|
| 옵시디언 | 개발 과정 기록, PAR 소재 축적 (나만 보는 창고) |
| 노션 | 외부 제출용 포트폴리오 (면접관에게 링크 공유) |
| GitHub | 커밋 히스토리 = 타임라인 증거 |

## 이력서 소재 (PAR — Problem · Action · Result)

### 개발 기록 시스템 구축
- **P**: 클로드 코드는 세션이 끊기면 맥락이 사라져 매번 재설명 필요
- **A**: CLAUDE.md로 프로젝트 컨텍스트를 영구 저장, docs/ 폴더로 일지 자동화
- **R**: 세션마다 브리핑 시간 제거, 1달 후 이력서 소재 20~30개 자동 축적 예정
