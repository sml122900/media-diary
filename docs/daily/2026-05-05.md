## 세션 2 추가 작업

### 3. TMDB 제목 자동 동기화 시도 → 실패 → 철거

기존 HTML에서 가져온 제목들이 TMDB 공식 제목과 다른 경우가 있어 자동 동기화를 시도했다.

- `useEffect` + `fetchTmdbTitle` 으로 tmdb_id 보유 항목 전체 순회 구현
- **문제 1**: React StrictMode가 개발 환경에서 effect를 두 번 실행 → cleanup이 `cancelled = true`로 루프 1건 후 중단
  - 해결: cleanup 제거, `useRef` 플래그로 재실행 차단
- **문제 2**: tmdb_id는 movie/tv 타입별 독립 네임스페이스 → anime 항목을 `tv` 타입으로 조회하면 완전히 다른 작품 ID → DB 전체 제목 오염
  - `이웃집 토토로` → `뽀빠이`, `살인의 추억` → `어벤져스` 등 178건 오염
  - Supabase SQL Editor에서 `DELETE FROM user_media WHERE user_id = 3` 후 재시딩으로 복구
  - 기능 전체 철거 결정

### 4. 검색 UX 개선 — 실시간 디바운스

- 기존: 검색창에 Enter 또는 버튼 클릭 필요
- 변경: 400ms 디바운스 useEffect로 타이핑 즉시 결과 갱신

## 배운 것 (세션 2)

- React StrictMode는 개발 환경에서 effect를 mount → unmount → mount 순으로 두 번 실행한다. cleanup이 있으면 비동기 루프가 1회 후 중단된다.
- TMDB movie ID와 TV ID는 완전히 다른 네임스페이스다. 같은 숫자라도 movie로 조회하면 A, tv로 조회하면 전혀 다른 B가 나온다.
- DB 오염 복구는 Supabase SQL Editor에서 직접 DELETE가 가장 빠르다.
