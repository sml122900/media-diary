## 트러블슈팅

### 1. seed-curation.js 재실행으로는 기존 오류 수정 불가
- **원인**: `ON CONFLICT (list_id, tmdb_id) DO NOTHING` — 잘못된 기존 항목이 그대로 유지됨
- **해결**: 별도 Node.js 스크립트로 직접 UPDATE/DELETE

### 2. UNIQUE 제약 위반
- **원인**: 올바른 ID가 이미 DB에 존재하는 경우 UPDATE 시 충돌
- **해결**: 올바른 ID가 이미 있으면 잘못된 항목 DELETE 처리

### 3. MCU 3개 순환 swap
- **원인**: 세 값이 서로 순환 참조 — A→B, B→C, C→A 형태라 직접 UPDATE 불가
- **해결**: 임시값(999999) 경유 4단계 UPDATE

### 4. Error 34 vs 번역 차이
- **원인 A**: TMDB에 실제로 없는 ID (→ 다른 영화 ID였던 것)
- **원인 B**: 한국어 제목 vs 영문 제목 반환 (false positive)
- **구분법**: API 직접 호출로 status_code 확인
