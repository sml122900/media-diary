# 2026-08-02 — 모바일 메뉴 레이아웃 깨짐 수정

## 배경

실기기(갤럭시 세로) 스크린샷에서 메뉴 관련 레이아웃 깨짐 제보.

- 메뉴가 열린 채 메인 화면과 겹쳐 보임
- 메뉴 열려도 배경(메인 콘텐츠)이 안 가려짐
- 메인 텍스트 왼쪽이 잘림 ("발견하기"→"견하기", "과거 기록 복원"→"록 복원")

## 진단 (Chromium 390px / 360px 재현)

`.menu-dropdown`은 사이드바가 아니라 헤더의 **absolute 드롭다운**이었다.
잘린 텍스트도 메인 콘텐츠가 아니라 **메뉴 항목 자체**의 텍스트였다.

측정값 (390px 뷰포트, 수정 전):

```
drawer rect  → left: -6, right: 154, width: 160, height: 999
menu-item    → left: -5  (첫 글자가 뷰포트 밖)
```

원인 2가지:

1. **좌측 잘림** — `.menu-dropdown { position: absolute; right: 0; min-width: 160px }`.
   모바일에서 `.mdb-controls`가 flex-wrap되면서 `≡ 메뉴` 버튼이 화면 왼쪽 근처로
   내려감 → 버튼 우측 끝 기준 오른쪽 정렬이라 드롭다운이 왼쪽으로 160px 뻗으며
   뷰포트 밖(-6px)으로 밀려남 → 항목 첫 글자 잘림.
2. **겹침** — 높이 999px로 뷰포트(844px)를 넘기는데 백드롭이 없어서
   메인 콘텐츠 위에 그냥 얹혀 보임. (메인을 밀어낸 것은 아니었음 —
   `.mdb-title` left는 열림 전후 모두 16px로 동일)

## 수정

`@media (max-width: 600px)`에서만 오버레이 드로어로 전환. 데스크톱은 무변경.

- `.menu-dropdown` → `position: fixed` 우측 드로어
  (`width: min(78vw, 300px)`, 전체 높이, 내부 스크롤, safe-area 패딩,
  `translateX(100%)` 슬라이드인)
- `.menu-backdrop` 신규 — `position: fixed; inset: 0`, 반투명 배경,
  `z-index: 1400` (드로어 1500), 탭하면 닫힘
- HomePage.jsx: `menuOpen && <div className="menu-backdrop" onClick={closeMenu} />`
  를 `.menu-wrap` 안에 렌더 (기존 외부 클릭 감지 `menuRef`와 충돌 없음)

| 항목 | 결과 |

| 데스크톱 1280px | `position: absolute`, width 180, 버튼 우측 정렬, 백드롭 `display: none` — 기존과 동일 |

## 실기기 설치 (갤럭시 R3KL20GA0EE)

`assembleDebug` → `adb install` 과정에서 코드와 무관한 환경 이슈 2건 발생.

### 이슈 1 — Java 버전 (`invalid source release: 21`)

```
> Task :capacitor-android:compileDebugJavaWithJavac FAILED
  error: invalid source release: 21
```

`JAVA_HOME`이 JDK 17(`C:\Program Files\Microsoft\jdk-17.0.20.8-hotspot`)인데
Capacitor 8의 `capacitor-android` 모듈은 Java 21로 컴파일된다.
설치된 JDK는 17과 Android Studio 번들 JBR 25 둘뿐이었다.

임시 우회 (환경변수·`gradle.properties` 미변경, 일회성 플래그):

```
.\gradlew.bat assembleDebug "-Dorg.gradle.java.home=C:\Program Files\Android\Android Studio\jbr"
→ BUILD SUCCESSFUL in 42s
```

**항구 해결 방침**: Adoptium Temurin 21 설치 후 `JAVA_HOME` 전환 (사용자 직접 진행 예정).
JBR 25 고정은 Gradle 8.14.3의 지원 상한(Java 24) 초과 + 경로 하드코딩 문제로 채택하지 않음.

### 이슈 2 — 서명 불일치 (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`)

```
Failure [INSTALL_FAILED_UPDATE_INCOMPATIBLE: Existing package com.mediadiary.app
signatures do not match newer version; ignoring!]
```

폰에 2026-07-31 00:54 사이드로드된 1.0.0이 설치돼 있었는데,
그것을 서명한 `~/.android/debug.keystore`가 소실돼 이번 빌드에서 Gradle이
keystore를 새로 생성(mtime = 빌드 시각) → 서명이 달라져 덮어쓰기 거부.

원래 keystore 복구가 불가하므로 사용자 승인 후 기존 앱 제거 → 재설치:

```
adb uninstall com.mediadiary.app  → Success
adb install -r app-debug.apk      → Success
확인: com.mediadiary.app 1.0.0, lastUpdateTime 2026-08-02 23:01:57
```

로컬 로그인 세션·화면모드 설정만 소실(재로그인 필요), 감상 기록은 Supabase에 보존.

**방침**: debug keystore 로컬 백업, 릴리스 keystore는 Stage 11.4 생성 시 클라우드+로컬 이중 백업.
