## 완료한 작업

### 1. Capacitor 패키지 설치 및 초기화

- `@capacitor/core @capacitor/cli @capacitor/android` 설치 (frontend)
- `npx cap init "미디어 다이어리" "com.mediadiary.app" --web-dir=dist` 실행
  - appId `com.mediadiary.app` 확정 (변경 불가 항목, 사용자 승인)
  - 프론트엔드가 tsconfig 없는 순수 JS 프로젝트라 `capacitor.config.ts`가 아닌 `capacitor.config.json`으로 생성됨 (동작은 동일)
- `capacitor.config.json`에 `server.androidScheme: "https"` 추가

### 2. Android 네이티브 프로젝트 생성 + 세로 모드 고정

- `npm run build` → `npx cap add android` → `frontend/android/` 네이티브 프로젝트 생성
- `AndroidManifest.xml`의 `MainActivity`에 `android:screenOrientation="portrait"` 추가 (카드 그리드·모달 위주 UX라 세로 고정으로 확정, Stage 11.1.2 결정 반영)
- `npx cap sync`로 웹 자산(dist) → `android/app/src/main/assets/public` 동기화

### 3. 디버그 빌드 검증

- `./gradlew assembleDebug` 실행 → **BUILD SUCCESSFUL**
- `android/app/build/outputs/apk/debug/app-debug.apk` (약 4.5MB) 생성 확인

### ANDROID_HOME 환경변수가 VSCode 재시작 후에도 반영되지 않음

- 자세한 내용은 [`docs/troubleshooting/android-home-env-not-reflected.md`](../troubleshooting/android-home-env-not-reflected.md) 참고
- 요약: 레지스트리(User 환경변수)에는 정상 등록되어 있었지만 세션 셸 프로세스가 계속 예전 환경 스냅샷을 사용 → 매 명령마다 `ANDROID_HOME`/`JAVA_HOME`을 직접 export하는 방식으로 우회, 빌드 자체는 정상 성공
