## 완료한 작업

### 1. 추가 버튼 후 즉시 표시 안 되는 버그 수정

**증상**: 작품을 추가한 뒤 새로고침을 해야 카드 그리드에 나타남

**원인 분석**:
- `HomePage.jsx`의 연도 범위 필터(`yearMin` / `yearMax`)는 앱 최초 로드 시 기존 컬렉션 기준으로 한 번만 계산됨
- `yearInitRef.current = true` 가드로 이후 재계산 차단
- 예: 기존 컬렉션이 1990~2023년 → `yearMax = 2023`으로 고정
- 2024년 신작 추가 시 `items` 배열에는 정상 추가되지만 `displayItems`의 연도 필터 (`year <= 2023`) 에 걸려 그리드에서 누락
- 새로고침 시 전체 재로드 → 연도 범위 재계산 → 표시됨

**수정 내용**:
- `handleAddAndExpandYear` 래퍼 함수 추가 (기존 `handleAdd` 대체)
- 추가된 항목의 연도가 현재 범위 밖이면 `yearMin`/`yearMax` 즉시 확장
- 기존 사용자 필터 조정 값은 건드리지 않고 범위 확장만 수행
- `AddModal`, `AiSearchModal`, `ScreenshotImportModal`, `CsvImportModal`, `QuickInputModal`, `DetailModal` 6곳 전부 교체

---

## 트러블슈팅

### 연도 범위 필터로 인한 추가 항목 누락

- **문제**: `yearInitRef.current`가 true가 된 이후 `items` 변경 시 `yearMin`/`yearMax` 재계산 없음
- **핵심**: `displayItems` useMemo가 `yearMin`/`yearMax`를 의존성으로 가지므로, 범위 밖 항목은 아예 렌더링 대상에서 제외됨
- **해결**: 항목 추가 시점에 범위를 확장하는 래퍼 패턴 적용
