## 기술 결정

| 결정 | 이유 |
|------|------|
| Claude tool_choice: any (강제 도구 호출) | 응답 구조 보장, JSON 파싱 불필요 |
| TMDB 3단계 fallback 검색 | 연도 불명확·타입 애매한 스크린샷 대응 |
| fill-tmdb-ids.js (batch TMDB 검색 스크립트) | 인터랙티브 없이 247개 ID 자동 매칭 |
| 내장 CSV 파서 (외부 라이브러리 미사용) | 의존성 최소화, Letterboxd 포맷 특화 |
| COALESCE 패턴 (life_period, watched_with 등) | 부분 업데이트 시 기존 값 보존 |
| 소프트 인증 (already_added) | 비로그인도 큐레이션 리스트 조회 가능 |
| category+region+media_type 3-key 계층화 | DB 신규 컬럼 없이 2단계 아코디언 그룹 구현 |
| person/search → person/:id/works 라우트 순서 | Express 패턴 매칭 충돌 방지 (리터럴 먼저 등록) |
| 시드 3스크립트 파이프라인 | fill→fetch-poster→seed 분리로 반복 실행 가능 (idempotent) |
