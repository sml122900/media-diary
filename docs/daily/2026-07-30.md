## 완료한 작업

### 1. Vercel 배포 `/policy/privacy` 404 수정

- 증상: `https://media-diary-chi.vercel.app/policy/privacy` 직접 접근 시 404 (Play Console 제출용 URL이라 실제로 열려야 함)
- 진단: `App.jsx`의 `/policy/:type` 라우트 자체는 정상. `frontend/vercel.json` 부재로 Vercel이 SPA 클라이언트 라우팅 경로를 서버에 없는 파일로 처리해 404를 반환
- 수정: `frontend/vercel.json` 신설, 모든 경로를 `index.html`로 rewrite하는 SPA fallback 설정 추가
- 부수 확인: 18개 커밋이 로컬에만 쌓여 origin에 push되지 않은 상태를 발견 → 사용자 승인 후 함께 push

### 2. TMDB 단일 검색 페이지네이션 누락 수정

- 증상: "짱구는 못말려" 검색 시 극장판이 10개 안팎만 표시 (실제 32편, 1993~2024)
- 진단: `searchTmdb()`가 TMDB `/search` API의 `page=1`만 조회하고 `total_pages`를 무시 → 결과가 20개(TMDB 1페이지 기본값) 이하로 잘림
- 수정: 최대 3페이지(60개)를 병렬 조회 후 `tmdb_id` 기준 dedupe, popularity 순 정렬 유지

### 3. 검색 띄어쓰기 미스매치 해결 (2개 영역)

- 증상: "다크나이트"(붙여쓰기) 검색 시 "다크 나이트"/"다크 나이트 라이즈" 누락, "파이트클럽"도 동일 증상. 작품 추가 검색(TMDB)과 내 목록 검색(로컬) 둘 다 발생
- 진단 결과 (보고 후 진행):
  - **작품 추가 검색(TMDB)**: TMDB가 한글 쿼리를 공백 기준으로 토큰 매칭 — 붙여쓴 쿼리는 결과가 실제로 누락됨 (우리 코드 문제 아님)
  - **내 목록 검색(로컬)**: 프론트 필터가 단순 `includes()`만 사용해 공백 유무를 그대로 비교 — 우리가 제어 가능한 문제
- 수정 A (내 목록 검색): 검색어·제목 양쪽에서 공백 제거 후 추가 비교하는 `qNoSpace` 정규화 추가
- 수정 B (TMDB 검색): 1차 결과가 3개 미만 + 공백 없는 한글(2~12자) 쿼리일 때만, 공백 1개를 각 위치에 삽입한 (길이-1)개 변형을 병렬 조회하는 fallback 추가. 최대 12개 변형 상한, 기존 결과와 병합 후 popularity 정렬. fallback까지 실패하면 "띄어쓰기를 다르게 시도해보세요" 안내 문구 표시
  - 자세한 배경은 [`docs/decisions/space-insertion-search-fallback.md`](../decisions/space-insertion-search-fallback.md) 참고

### 4. 토큰 잔액 🪙 이모지 tofu 렌더링 수정

- 증상: 일부 환경(구형 Android WebView)에서 🪙가 빈 네모(tofu)로 표시됨. Capacitor로 다양한 기기에 배포 예정이라 위험도 높음
- 원인: 🪙(U+1FA99)는 Unicode 13.0(2020) 도입 — 코드베이스의 다른 이모지 대부분(Unicode 6.0, 2010)보다 훨씬 신규라 폰트 지원 범위가 좁음
- 수정: `TokenIcon.jsx` 신설 (lucide "coins" 아이콘을 재현한 인라인 SVG, `stroke="currentColor"`로 주변 텍스트 색 자동 상속). 토큰 잔액 표시 9곳(헤더 칩, 메뉴, 토큰 부족 모달, 스크린샷/Discover/DiscoverChat/MemoryChat/ReportsCustomize) 전부 교체
- 부수 조사: 다른 이모지(🎬 등) 위험도 점검 — 대부분 Unicode 6.0~7.0(2010~2014)로 안전, 🛒🤖🥇🥈🥉🤷 정도가 Unicode 8.0~9.0(2015~16)라 상대적 중간 위험군. 지금은 교체하지 않고 파악만 완료
