# AI 검색이 엉뚱한 동명 작품을 반환 — 평점 정렬의 표본 크기 함정

## 문제 상황

AI 자연어 검색에서 "우주 배경의 잔잔한 SF 영화"를 검색하면 AI 해석은 정확한데
("우주 배경의 철학적이고 잔잔한 SF") 결과가 엉뚱했다.

```
The Arrival (2017)     ← SF 아님
Arrival (2013)         ← 산악자전거 다큐멘터리
NXT ArRIVAL (2014)     ← 프로레슬링
```

노린 것은 컨택트(*Arrival*, 2016)인데 목록에 없었다. 줄거리도 영문으로 내려왔다.

같은 기능에서 "90년대 홍콩 느와르"는 **0건**이었다. 이건 `token_usage_log`에
`empty_result: true`로 기록돼 있어 실사용 실패라는 게 확인됐다.

## 시도한 것들

### 1. AI가 뭘 반환하는지부터 확인

매칭이 문제라고 단정하지 않고, 백엔드와 **동일한 프롬프트로 Claude를 직접 호출**해 원문을 봤다.

| 쿼리 | `keywords` 실제 응답 |
|---|---|
| 우주 배경의 잔잔한 SF 영화 | `Solaris, Stalker, 2001 A Space Odyssey` |
| 90년대 홍콩 느와르 | `Hong Kong noir 1990s` |
| 크리스토퍼 놀란 SF | `Christopher Nolan` |

여기서 **두 증상의 원인이 다르다**는 게 드러났다. 홍콩 느와르는 AI가 장르 설명어를 냈고,
TMDB는 제목 색인이라 그 문자열로는 0건이 나온다. 매칭 실패가 아니라 상류 문제였다.
프롬프트가 `"영어 작품 제목 또는 핵심 단어"`라고 써서 설명어를 허용하고 있었다.

덤으로 회귀 기준으로 삼으려던 "크리스토퍼 놀란 SF"도 이미 깨져 있었다 — 인물명으로 검색하니
TMDB가 놀란에 **관한** 다큐 4건만 돌려줬고 인셉션·인터스텔라는 없었다.

### 2. TMDB 응답을 직접 계측

`query=Arrival`을 코드와 동일한 방식으로 호출해 정렬 결과를 찍어봤다.

```
[vote_average 내림차순 — 코드의 정렬]
8.3점 (표     3개, 인기 0.5)  The Arrival (2017)
8.0점 (표     1개, 인기 2.4)  Arrival (2013)
7.8점 (표     4개, 인기 0.7)  NXT ArRIVAL (2014)
7.6점 (표 19,635개, 인기 24)  Arrival (2016)   ← 4위

[인기도 내림차순 — 참고]
인기 24  / 7.6점(표 19,635)  Arrival (2016)   ← 1위
```

**표 1~4개짜리가 평균 8점대로 19,635표의 진짜 작품을 이긴다.** 사용자가 본 결과 3편과 정확히
일치했다. 코드를 다시 보니 매칭 로직이라 부를 게 없었다 — 전체 결과를 `vote_average`로 정렬해
상위 8개를 자르는 게 전부였고, 연도 검증도 제목 유사도도 표수 하한도 없었다.

### 3. 언어 파라미터 확인

영어 키워드는 `language=en-US`, 한국어 키워드는 `ko-KR`로 검색하고 있었다. 영어 키워드가 매칭이
잘 되니 결과 대부분이 en-US 응답이라 제목·줄거리가 영문이었다.

```
en-US: title="Arrival"  overview="Taking place after alien crafts land aro…"
ko-KR: title="컨택트"    overview="어느 날 전 세계 12개 지역에 외계 비행물체 셸이…"
```

단, 한국어 번역이 없는 작품은 `ko-KR`에서 `overview`가 **빈 문자열**로 온다(Stalker 검색 4건 모두
길이 0). TMDB는 fallback을 해주지 않는다.

## 최종 해결법

원인이 셋이라 셋 다 고쳤다.

1. **AI 응답 구조화** — `tool_choice: any` + `works[{title, original_title, year, tmdb_type}]`를
   required로 강제. 프롬프트에서 "또는 핵심 단어"를 빼고 실제 작품만 요구했다.
   예시로 실제 작품명(Arrival, Parasite)을 들면 AI가 그 예시를 그대로 답으로 뱉는 회차가 있어
   예시도 교체했다. 연도·원제가 생기면서 **TMDB 결과를 검증할 기준**도 함께 생겼다.
2. **매칭 점수화** — `tmdbMatch.js` 신설. 제목 유사도 + 연도 근접도 + 표수 가중으로 점수를 매겨
   최고점 1건만 채택하고, 임계 미달이면 결과에서 제외한다.
3. **`ko-KR` 통일 + 원어 fallback** — `overview`가 비면 원어 상세 조회로 채운다.

구현 중 실측으로 세 번 더 보강했다. 각각 별개의 실패 모드였다.

- **원제가 원어** — 타르코프스키 *Stalker*의 TMDB 원제는 `Сталкер`라 유사도가 무력해져,
  한국 제목이 우연히 같은 *One Hour Photo*(한국 제목 "스토커")가 이겼다.
  → 연도를 걸고 검색했는데도 TMDB가 돌려줬다는 사실에 가산점.
- **그 가산점이 쓰레기를 통과시킴** — 홍콩 느와르 결과에 *TMNT: Case of the Killer Pizzas*(표 6개),
  *Gunfire*(1950, 표 2개)가 섞였다. → 제목이 안 닮은 매칭은 "연도 정확 일치 + 표 100개 이상"일
  때만 신뢰.
- **부분 문자열** — `"Snowpiercer"` ⊂ `"Snowpiercer International Special Animation"`이 0.85를
  받아 표 1개짜리 애니가 설국열차를 밀어냈다. → 포함 관계 점수를 길이 비율로 스케일.

결과:

| 쿼리 | 이전 | 지금 |
|---|---|---|
| 우주 배경의 잔잔한 SF | The Arrival(2017)·Arrival(2013 다큐)·NXT ArRIVAL | 인터스텔라·그래비티·2001·**컨택트(2016)**·솔라리스·마션 |
| 90년대 홍콩 느와르 | **0건** | 첩혈속집·중경삼림·영웅본색 2,3·종횡사해·흑협 |
| 크리스토퍼 놀란 SF | 놀란에 관한 다큐 4건 | 인셉션·인터스텔라·테넷·오펜하이머·프레스티지 |

## 이력서 소재 한 줄

> 외부 API의 평균 평점이 표본 1개에서도 계산된다는 점을 계측으로 밝혀내, 평점 단독 정렬을
> 제목 유사도·연도·표본 크기 다중 신호 점수화로 교체하고 검색 정확도 실패(0건 또는 오매칭)를 해소했다.
