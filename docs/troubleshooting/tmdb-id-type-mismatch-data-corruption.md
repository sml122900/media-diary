# TMDB ID 타입 불일치로 DB 제목 전체 오염

## 문제 상황

TMDB 제목 자동 동기화 기능을 실행했더니 기존 제목들이 완전히 엉뚱한 제목으로 덮어씌워졌다.

```
이웃집 토토로 → 뽀빠이
살인의 추억   → 어벤져스
드래곤볼Z    → Robinson
천공의 성 라퓨타 → Here Come the Brides
```

178건 중 다수가 오염되었고, 기존 제목을 복원할 방법이 없었다.

## 시도한 것들

1. 동기화 로직에서 `tmdb_id`와 `type` 필드 확인
   - `item.type === 'movie'` → TMDB `movie` 엔드포인트 호출
   - `item.type === 'anime' || 'drama'` → TMDB `tv` 엔드포인트 호출
2. 콘솔 로그로 응답 확인
   - TMDB가 `404`를 반환하거나, 전혀 다른 작품 제목을 반환

## 최종 해결법

**원인**: TMDB의 movie ID 네임스페이스와 TV ID 네임스페이스는 완전히 독립적이다.
`이웃집 토토로`의 `tmdb_id`는 movie 기준으로 저장되어 있었는데, anime이므로 `tv` 타입으로 조회하면 해당 숫자를 ID로 가진 전혀 다른 TV 프로그램이 반환된다.

```
movie/12345 = 이웃집 토토로
tv/12345    = 뽀빠이  ← 완전히 다른 작품
```

**복구**: Supabase SQL Editor에서 직접 삭제 후 재시딩
```sql
DELETE FROM user_media WHERE user_id = 3;
```
localStorage의 시딩 플래그도 제거 후 앱 새로고침으로 178건 재삽입.

**근본 해결**: 제목 자동 동기화 기능 전체 제거.
앞으로 사용자는 TMDB 검색 결과를 직접 선택해서 추가하므로 제목과 tmdb_id가 항상 정확히 매핑된다.

## 이력서 소재 한 줄

외부 API(TMDB)의 movie/TV ID 네임스페이스 독립 구조를 파악하지 못해 DB 178건 오염이 발생했고, 원인 분석 후 자동 동기화 설계를 철회하고 데이터 무결성을 우선하는 방향으로 재설계함.
